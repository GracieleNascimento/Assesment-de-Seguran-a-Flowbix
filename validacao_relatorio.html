Recomendação: Desabilitar auth.anonymous, salvo dashboards públicos intencionais; nunca com papel Admin/Editor.

Por que isso é um risco: Chaves de API e service accounts são credenciais permanentes sem MFA. Sem expiração, uma chave vazada em script ou repositório continua válida indefinidamente.

Impacto potencial: Acesso programático ao Grafana por tempo ilimitado.

Cloudflare 2023: token de API não rotacionado foi reutilizado por atacante (2023)
Um token de API e credenciais vazados num incidente anterior não foram rotacionados e, meses depois, foram usados para acessar sistemas internos. A lição oficial foi dar expiração e rotacionar todo token.
Fontes: Cloudflare Blog – Thanksgiving 2023 security incident
Uber 2022: credencial de administrador em texto claro num script deu acesso amplo (2022)
Depois de entrar na rede, o atacante encontrou um script com a credencial de administrador do cofre de senhas (PAM) em texto claro, o que ampliou muito o alcance do incidente. Reforça por que segredos não devem ficar em texto claro em arquivos, scripts ou macros.
Fontes: GitGuardian – Uber breach 2022 · UpGuard – What caused the Uber data breach in 2022

Recomendação: Definir expiração para chaves/tokens, com papel mínimo, e revogar as sem uso.

Não conformeALTObloqueanteGRF-06 · Frontend do Grafana somente via HTTPSGrafana

Evidência: Frontend acessado por HTTP (http://127.0.0.1:57514).

Por que isso é um risco: Grafana em HTTP envia login, sessão e dados em texto claro, legíveis por quem observa a rede.

Impacto potencial: Captura de credenciais e sessões de administradores.

MITRE ATT&CK: T1040 (Network Sniffing), T1557 (Adversary-in-the-Middle)

Casos reais documentados:

Rebaixamento de HTTPS para HTTP quando falta HSTS (2009)
Sem HSTS, o primeiro acesso em HTTP pode ser interceptado e mantido sem criptografia para capturar credenciais (técnica de SSL stripping). O HSTS foi criado justamente para impedir esse rebaixamento.
Fontes: OWASP – HTTP Strict Transport Security Cheat Sheet

Recomendação: Definir server.protocol=https (ou TLS no proxy) e redirecionar HTTP.
